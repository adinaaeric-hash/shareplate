# SharePlate – Smart Food Allocation Website

A web platform that connects food donors with NGOs and recommends suitable donations using a smart matching algorithm based on distance, expiry time, quantity and storage capacity.

## Features
- Donor, NGO and Administrator roles with secure login
- Food listings with expiry handling
- Smart matching and ranking of donations for NGOs
- Donation requests with quantity validation (no over-allocation)
- Pickup tracking and notifications
- Impact dashboard

## Technology
- Frontend: Next.js, Tailwind CSS
- Backend: Python, FastAPI, SQLAlchemy
- Database: Microsoft SQL Server Express (SQLite for development only)
- Testing: Pytest
- Version control: Git and GitHub

## Project Structure
- `docs/` – SRS, SDS and low-fidelity sketches
- `backend/` – FastAPI application (models, repositories, services, controllers)
- `frontend/` – Next.js application
- `PROGRESS_LOG.md` – weekly progress record
